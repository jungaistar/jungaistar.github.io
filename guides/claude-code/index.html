💡 가이드 사용법

  • HTML 파일을 브라우저(크롬·엣지)로 여세요. 슬라이드 형태로 위에서 아래로 스크롤하며 봅니다.
  • 명령어 오른쪽 위 주황색 [복사] 버튼을 누르면 클립보드에 담깁니다. PowerShell에서는 마우스 오른쪽 클릭으로 붙여넣습니다.
  • 인쇄하거나 PDF로 저장하려면 Ctrl+P → 용지 가로, 배율 배경 그래픽 켜기 로 설정하세요. (복사 버튼은 인쇄에서 자동으로 빠집니다)
  • 화면 그림에 있는 주황색 원 번호는 오른쪽 실행 순서 번호와 같습니다. 그림에서 위치를 찾고, 오른쪽에서 설명을 읽으세요.
  • 막히면 각 가이드 뒤쪽의 문제 해결 슬라이드를 먼저 확인하세요. 대부분은 터미널을 새로 열면 해결됩니다.
  • .md 파일은 그림 없는 텍스트 버전입니다. 메모장·노션·깃허브에 붙여넣어 배포할 때 사용하세요.
