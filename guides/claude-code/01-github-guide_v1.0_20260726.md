# GitHub 계정 만들고 _내 저장소 열기_

**CLAUDE CODE 준비 · 01 GITHUB — v1.0 · 2026-07-26**

> 클로드 코드로 만든 프로그램을 보관하고 공유할 GitHub 계정을 만듭니다. 화면 그림의 **주황색 번호**와 오른쪽 **실행 순서 번호**가 같습니다.
> 소요 시간 약 10분 · 설치 프로그램 없음(웹) · 완전 무료 · 초보자 대상

> 📌 화면 그림(목업)이 포함된 버전은 같은 폴더의 **01-github-guide_v1.0_20260726.html** 을 브라우저로 여세요. 명령어는 HTML에서 `복사` 버튼으로 바로 복사할 수 있습니다.

## GitHub 준비 전체 흐름

가입 → 인증 → 2단계 인증 → 로그인 확인 → 저장소 만들기 순서입니다. 프로그램을 설치하는 것이 아니라 **웹사이트에 회원가입**하는 과정입니다.

| 순서 | 단계             | 하는 일   |
| :--: | :--------------- | :-------- |
|  01  | 🌐 접속·가입     | STEP 1–4  |
|  02  | 📧 이메일 인증   | STEP 5    |
|  03  | 🔐 2단계 인증    | STEP 6    |
|  04  | 🏠 로그인 확인   | STEP 7    |
|  05  | 📦 저장소 만들기 | STEP 8–10 |

**준비물:** 인터넷 브라우저(크롬·엣지) · 본인 이메일 주소 · 스마트폰(2단계 인증용) · 약 10분 | 비용 0원(Free 플랜)

## STEP 1 — github.com 접속 후 **Sign up** 누르기 <sub>GITHUB · 가입 시작</sub>

**목표:** 브라우저로 GitHub 홈페이지에 들어가 회원가입 화면을 엽니다.

1. 크롬(또는 엣지)을 열고 주소창에 **github.com** 을 입력한 뒤 Enter.
2. 검은 배경에 **Let's build from here** 가 보이면 제대로 들어온 것입니다.
3. 오른쪽 위 **Sign up**(초록 버튼)을 클릭합니다.

> 💬 **용어 정리** — GitHub는 **코드와 파일을 온라인에 보관하고 함께 작업하는 창고**입니다. 클로드 코드로 만든 프로그램도 여기에 올려 보관·공유합니다.

> ℹ️ **주소를 정확히** — `github.com` 입니다. `github.co`, `gitgub.com` 같은 오타 사이트를 조심하세요.

## STEP 2 — 이메일 주소 입력 → **Continue** <sub>GITHUB · 가입 정보</sub>

**목표:** 가입에 사용할 본인 이메일 주소를 넣습니다.

1. **Enter your email** 칸에 실제로 **메일을 받을 수 있는** 주소를 입력합니다.
2. 초록색 **Continue** 버튼을 클릭합니다.
3. Google 계정이 있다면 아래 **Continue with Google** 로 더 빠르게 가입할 수도 있습니다.

> ⚠️ **반드시 받는 메일함이 있어야 합니다** — 조금 뒤 **인증 코드**가 이 주소로 옵니다. 회사 메일이 외부 메일을 막는 경우 개인 메일(gmail/naver)을 쓰세요.

## STEP 3 — 비밀번호 · 아이디 정하기 <sub>GITHUB · 가입 정보</sub>

**목표:** 로그인에 쓸 비밀번호와, 나를 나타내는 아이디(Username)를 정합니다.

1. **Password** 칸에 비밀번호를 입력합니다. (영문+숫자 15자 이상 권장)
2. **Username** 칸에 원하는 아이디를 입력합니다. 초록색 **available** 이 뜨면 사용 가능합니다.
3. 광고 수신 칸에는 **n** 을 입력합니다.
4. **Continue** 를 누릅니다.

> ℹ️ **아이디는 인터넷 주소가 됩니다** — 아이디가 `hufs-hong` 이면 내 페이지는 `github.com/hufs-hong` 이 됩니다. **영문 소문자·숫자·하이픈(-)** 만 쓰세요.

> ⚠️ **not available 이 뜨면** — 이미 쓰는 사람이 있다는 뜻입니다. 예: `hong-hufs`, `hufs-hong2`

## STEP 4 — 사람 확인(퍼즐) 통과하기 <sub>GITHUB · 로봇 아님 확인</sub>

**목표:** 자동 가입 프로그램이 아님을 확인하는 간단한 퍼즐을 풉니다.

1. 퍼즐 그림이 나오면 안내대로 **동물의 방향을 화살표에 맞춥니다.**
2. 초록색 **확인 완료** 표시가 뜨는지 봅니다.
3. **Create account** 버튼을 눌러 가입을 확정합니다.

> ⚠️ **퍼즐이 계속 실패한다면** — ① 브라우저 배율을 **100%**로(Ctrl+0) ② 광고 차단 확장 끄기 ③ 크롬 **시크릿 창**(Ctrl+Shift+N)에서 재시도.

> 💬 **천천히 하세요** — 실패해도 **다시 시도**가 무제한입니다. 당황하지 말고 반복하세요.

## STEP 5 — 메일로 온 **8자리 코드** 입력 <sub>GITHUB · 이메일 인증</sub>

**목표:** 입력한 이메일이 본인 것임을 증명해 가입을 확정합니다.

1. 가입한 메일함을 열어 **GitHub** 이 보낸 메일을 찾습니다.
2. 메일 안의 **여덟 자리 숫자 코드**를 확인합니다.
3. 가입 화면의 칸에 코드를 그대로 입력합니다. (자동으로 다음 칸 이동)

> ⚠️ **메일이 안 보일 때** — ① **스팸함/프로모션함** 확인 ② 1~2분 뒤 **Resend code** 클릭 ③ 그래도 없으면 주소 오타 → 뒤로 가서 이메일 다시 입력.

> ✅ **성공 신호** — 코드가 맞으면 **화면이 자동으로 넘어갑니다.** 설문이 나오면 **Skip** 해도 됩니다.

## STEP 6 — 2단계 인증(2FA) 켜기 <sub>GITHUB · 보안 설정</sub>

**목표:** 스마트폰 인증 앱을 등록해 계정을 안전하게 잠급니다. (프로필 → Settings → Password and authentication)

1. **Enable 2FA** 버튼을 누릅니다.
2. 스마트폰의 **Microsoft Authenticator**(또는 Google OTP) 앱으로 **QR 코드**를 찍습니다.
3. 앱에 나온 **6자리 숫자**를 화면에 입력합니다.
4. 마지막에 나오는 **복구 코드**를 반드시 저장/인쇄해 둡니다.

> ⚠️ **복구 코드는 꼭 보관하세요** — 휴대폰을 잃어버리면 **복구 코드가 유일한 열쇠**입니다. 캡처해 개인 메일로 보내두거나 인쇄해 보관하세요.

## STEP 7 — 로그인 상태 확인 (이게 "실행"입니다) <sub>GITHUB · 구동 확인</sub>

**목표:** GitHub는 설치 프로그램이 아니라 웹사이트입니다. 로그인된 첫 화면을 여는 것이 곧 실행입니다.

1. 주소창에 **github.com** 을 입력합니다.
2. 오른쪽 위에 **내 프로필 사진**이 보이면 로그인된 상태입니다.
3. 가운데 활동 화면이 보이면 그것이 **내 홈(대시보드)** 입니다.

> ✅ **다음부터는 이렇게 여세요** — 브라우저 즐겨찾기에 **github.com** 을 추가해 두면 클릭 한 번으로 들어올 수 있습니다. (Ctrl+D)

> ⚠️ **로그인 화면이 계속 나온다면** — 브라우저 **쿠키 차단** 설정 때문일 수 있습니다. 크롬 설정 → 개인정보 → 쿠키 → **타사 쿠키 허용** 후 재시도.

## STEP 8 — 초록색 **New** 버튼 누르기 <sub>GITHUB · 저장소 만들기</sub>

**목표:** 내 프로그램을 담을 새 저장소(Repository) 만들기를 시작합니다.

1. 왼쪽 **Top repositories** 옆의 초록색 **New** 버튼을 클릭합니다.
2. 버튼이 안 보이면 오른쪽 위 **＋** 를 누릅니다.
3. 열린 목록에서 **New repository** 를 선택합니다.

> 💬 **저장소(Repository)란?** — 프로젝트 하나당 폴더 하나라고 생각하면 쉽습니다. **프로그램 하나 = 저장소 하나** 로 만들면 관리가 편합니다.

> ℹ️ **몇 개까지 만들 수 있나요?** — Free 플랜에서도 **공개·비공개 저장소를 개수 제한 없이** 만들 수 있습니다.

## STEP 9 — 이름 입력 후 **Create repository** <sub>GITHUB · 저장소 만들기</sub>

**목표:** 저장소 이름과 공개 여부를 정하고 실제로 만듭니다.

1. **Repository name** 에 영문 이름을 입력합니다. 예: `my-first-app`
2. **Public**(전체 공개) 또는 **Private**(나만 보기) 중 하나를 고릅니다.
3. **Add a README file** 을 체크합니다. (설명 파일이 자동 생성)
4. 맨 아래 초록색 **Create repository** 를 클릭합니다.

> ℹ️ **이름 규칙** — 영문 소문자·숫자·하이픈(-)만 쓰세요. **한글·공백은 피하는 것이 안전**합니다.

> ⚠️ **Public / Private 선택** — 업무 자료·개인정보가 들어갈 예정이면 반드시 **Private**. 강의 실습용은 Public 이어도 됩니다.

## STEP 10 — 저장소 주소 복사해 두기 <sub>GITHUB · 주소 확인</sub>

**목표:** 나중에 클로드 코드/Git에서 쓸 저장소 주소(URL)를 확인하고 복사합니다.

1. 저장소 화면 오른쪽 위 초록색 **<> Code** 버튼을 클릭합니다.
2. **HTTPS** 탭이 선택돼 있는지 확인합니다.
3. 주소 오른쪽 **복사 아이콘**을 누릅니다.

**내 저장소 주소 형태 (아이디·이름만 바꿔 쓰세요)**

```powershell
https://github.com/hufs-hong/my-first-app.git
```

> ✅ **이 주소를 어디에 쓰나요?** — 다음 가이드(Git)에서 `git clone <주소>` 로 내 컴퓨터에 내려받을 때 사용합니다.

## GitHub 관련 주소·명령어 모음

오른쪽 위 **복사** 버튼을 누르면 클립보드에 담깁니다. 붙여넣기는 **Ctrl+V** (터미널은 마우스 오른쪽 클릭).

### ① GitHub 홈 (즐겨찾기 추천)

```powershell
https://github.com
```

로그인 후 첫 화면(대시보드)으로 이동합니다.

### ② 새 저장소 바로 만들기

```powershell
https://github.com/new
```

메뉴를 거치지 않고 저장소 생성 화면으로 바로 갑니다.

### ③ 보안(2단계 인증) 설정

```powershell
https://github.com/settings/security
```

2FA 켜기·복구 코드 다시 보기.

### ④ 내 프로필 페이지

```powershell
https://github.com/아이디
```

**아이디** 부분만 본인 것으로 바꾸세요. 예: github.com/hufs-hong

### ⑤ 내 저장소를 컴퓨터로 내려받기 (다음 Git 가이드에서 사용)

```powershell
git clone https://github.com/hufs-hong/my-first-app.git
```

주소의 **아이디/저장소이름** 을 본인 것으로 바꿔서 사용합니다.

### ⑥ 로그인 계정 확인 (Git 설치 후)

```powershell
git config --global user.name
```

```
→ 설정한 이름이 출력되면 정상
```

Git 가이드에서 설정한 이름이 GitHub 아이디와 달라도 괜찮습니다.

## GitHub — 문제가 생겼을 때

자주 나오는 상황과 해결 방법입니다. 위에서부터 순서대로 확인해 보세요.

| 이런 화면·메시지가 나오면            | 원인                       | 이렇게 해결하세요                                                                                                                                               |
| :----------------------------------- | :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 인증 코드 메일이 오지 않음           | 스팸 분류 또는 이메일 오타 | ① **스팸함·프로모션함** 확인 ② 2분 후 **Resend code** ③ 그래도 없으면 뒤로 가서 이메일 주소를 다시 확인. 회사 메일이 막는 경우가 많으니 **개인 메일**로 재시도. |
| `Username is not available`          | 이미 사용 중인 아이디      | 뒤에 소속·숫자를 붙여 다시 시도. 예: `hong-hufs`, `hufs-hong2`. 영문 소문자·숫자·하이픈만 가능하며 **\_ 와 공백은 불가**.                                       |
| 사람 확인(퍼즐)이 계속 실패          | 확대 배율·광고 차단 확장   | ① **Ctrl+0** 으로 배율 100% ② 광고 차단 확장 끄기 ③ **시크릿 창(Ctrl+Shift+N)** 에서 재시도 ④ 다른 브라우저(엣지) 사용.                                         |
| 로그인은 되는데 계속 코드를 물어봄   | 2단계 인증(2FA) 정상 동작  | 휴대폰 인증 앱의 **6자리 숫자**를 입력합니다. 폰이 없으면 가입 시 저장한 **복구 코드** 사용. **Remember this device** 를 체크하면 다음부터 덜 묻습니다.         |
| 휴대폰을 바꿔 인증 앱이 없어짐       | 2FA 기기 분실              | 로그인 화면에서 **Use a recovery code** 클릭 → 저장해 둔 복구 코드 입력 → 들어간 뒤 **Settings → Password and authentication** 에서 2FA 재등록.                 |
| 저장소를 잘못 만들었음 / 지우고 싶음 | 이름·공개설정 실수         | 해당 저장소 → **Settings** → 맨 아래 **Danger Zone** → **Delete this repository**. 이름 바꾸기는 같은 Settings 상단 **Repository name** 에서 가능.              |
| 화면이 전부 영어라 어렵다            | 한국어 UI 미지원 영역      | 크롬에서 페이지 **오른쪽 클릭 → 한국어로 번역**. 단, 번역하면 버튼 이름이 달라지므로 **이 가이드의 그림과 위치**로 찾는 편이 빠릅니다.                          |
